# ProSurface Premium Concept

A custom high-motion concept site for ProSurface Performance Courts using supplied project photography and branding.

## Preview
Open `index.html` in a browser. For best results, serve the folder locally (for example with VS Code Live Server).

## Included interactions
- cinematic full-screen hero with scroll parallax
- custom cursor and magnetic-style interaction targets
- editorial project storytelling
- animated service index
- draggable before/after coating transformation
- scroll reveal motion and progress indicator
- responsive mobile choreography
